# Explicit reusable pilot evidence

Four original Wells/Wiscasset source versions are pinned by body, text and native
retrieval-metadata hashes. The config explicitly maps worker shorthand aliases to
those retained pilot versions; aliases are not new fetch attempts. The existing
pinned-evidence verifier rehashes all referenced bytes before any quote check.

This restores provenance for reused source excerpts without renewing retrieval
or legal-force dates. Existing Wells and Wiscasset ballot review packets retain
their certification, wording and implementation limits. No canonical promotion
occurs through this configuration.

# Proposed national discovery phase

The [operating proposal](../../../../docs/national-discovery-batch-2026-11-08.md), [exact query plan](plan.json) and [preview](preview.json) define 600 state/sector/lane cells and 1,200 provider calls, with a proposed $25 allocated search ceiling, 500 source fetches and 20 Pydoll reservations. No provider calls or live run namespace are authorized by these files. Existing spend and ledgers remain intact; model API extraction and factual promotion are not included. Raw payloads and account metadata remain private.

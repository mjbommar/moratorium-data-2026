# 90-record state-policy scope reconciliation

Six bounded Terra primary cohorts and six independent cohorts reviewed 90 previously unreviewed observations using retained evidence. The coordinator checked all 90 current row/identity guards, 155 body/text/passage references and registry-candidate evidence links before appending the decisions. There were no new searches or source acquisitions in this wave. The raw CSV and all 447 IDs are unchanged.

The batch adds **77 includes, two excludes and 11 unresolved decisions**. Current partitions are **125 included / five excluded / 13 reviewed-unresolved / 304 unreviewed**. The exploratory pool contains 442 observations; neither it nor the 125 reviewed inclusions is a deduplicated instrument census.

Independent review corrected several overly strict primary holds: explicit official legislative summaries can establish physical-infrastructure proposal scope without proving exact operative terms or enactment. Alaska HCR 3's task-force duties expressly address establishing and operating data centers. Conversely, Arkansas SB 307's 100 MW generation criterion is not a data-center customer-load threshold; that general utility-investment act is excluded. Iowa HF 2198's financial-disclosure database is also excluded from this infrastructure scope. The unresolved cases retain specific definition, version or authority questions rather than guessed applicability.

Composite observations remain intact. An included composite may contain distinct measures and unrelated components; inclusion does not establish every component's scope, exact carrier identity, current force or independence. [Application receipt](application.json) pins registry changes and decision IDs; [source checks](source-checks.json) retain URL/hash/locator references. Bodies, transcripts, full quotations and detailed worker reviews remain private.

This is scope review, not whole-record freshness or current-law acceptance. Source-specific freshness, the remaining observations, final consumer updates and the release remain open.

# Prospective rule-unit accounting and scoring development

The actual extractor → native SDK → controlled mock HTTP → audit path now binds a pre-dispatch workload anchor to the complete source/model/settings context. The audit independently checks logical order and retained HTTP reservation order, actual serialized requests, responses and boundary outputs. Missing, extra, swapped or mismatched evidence fails closed without erasing observed lower bounds. Requested endpoint observation does not authenticate the provider, TLS peer, DNS or proxy. Historical histories remain unknown lower bounds; no old run is retroactively authenticated.

Independent review reproduced a two-unit HTTP-ordering defect. The fix was rechecked with the original reviewer probe: valid order passes; reversed HTTP pairs are incomplete and retain a reservation lower bound of two. The scorer review also found an undocumented pooled gate, a shrinking support denominator, incorrect slot/support coupling and incomplete reporting. The corrected contract retains the original 95% clause-support/change-unit/change-slot thresholds and zero high-impact errors, with calibration and pooled/control coverage diagnostic. Independent structured probes confirm the repaired cases. A subsequent malformed quote-container defect was corrected by the coordinator and rerun against the original independent probes: it is unscorable, retains the 1-clause denominator and credits zero supported clauses.

The scorer records per-unit/family and change/control/pooled coverage, literal quote offsets, explicit nonextractable issues, individual errors and adjudications. Structured input and hashes do not prove semantic truth, independence, full-source completeness, chronology or unexposed holdout selection. Missing/unparseable boundary output preserves an unknown denominator and `not_scored`; this conservative status is not identical to the original protocol's explicit gate-failure wording. All generated clauses with known population remain counted even without review.

The coordinator's **84-test** rule-unit suite passed, including **20 scorer tests**; these are overlapping counts, not 104 tests. Eleven independent synthetic scorer probes were rerun.

# DC-26-0003: Data Centers

## Background

On June 2, 2026, the Board of County Commissioners authorized staff to update the [Boulder County Land Use Code](https://bouldercounty.gov/property-and-land/land-use/planning/land-use-code/) as it relates to data center uses.

**Documents:**

* [Authorization under the Boulder County Land Use Code for Text Amendments to the Land Use Code related to Data Centers](https://pub-bouldercounty.escribemeetings.com/filestream.ashx?DocumentId=43663)

Please note that any proposed changes to the Boulder County Land Use Code are for unincorporated areas in Boulder County, not in cities like Boulder or Longmont. Boulder County’s unincorporated areas are comprised of the rural, mountainous and plains communities that are not part of any incorporated municipality.

The Board of County Commissioners expressed concerns about the potential land use impacts of data centers. Many communities are facing challenges related to the development of resource-intensive data centers. The primary concern is that the Code does not currently define data centers as specific uses, identify the scale at which they may or may not be appropriate in the unincorporated county, or identify zoning districts in which the use may or may not occur. The Commissioners expressed interest in prohibiting these uses in the unincorporated county. Through a Code change, staff will define these uses and identify the places and scale at which they may or may not be permitted in the unincorporated county.

As part of this process, the Boulder County Commissioners also enacted a temporary moratorium effective June 2, 2026. While the moratorium is in effect, Community Planning and Permitting will not accept any applications for data centers. The moratorium will be in effect for six months while changes to the Land Use Code are considered.

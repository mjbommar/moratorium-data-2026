#### Ordinance No. 834

meeting

Adopted 12/22/25

The purpose of this item is to bring the Town's various codes into alignment with the respective 2024 codes promulgated by the International Code Council (ICC). These codes includes, the International Building Code (2024 Edition); the International Residential Code for One– and Two–Family Dwellings (2024 Edition); the International Fuel Gas Code (2024 Edition); the International Plumbing Code (2024 Edition); the International Mechanical Code (2024 Edition); the International Existing Building Code (2024 Edition); the International Property Maintenance Code (2024 Edition); the International Swimming Pool and Spa Code (2024 Edition); and the International Energy Conservation Code (2024 Edition), Colorado Wildfire Resiliency Code, and Colorado Model Electric and Solar Ready Code

#### Ordinance No. 831

meeting

Adopted 12/22/25

Consider adoption of Ordinance 2025-831 amending sections in Chapter 16 of the Land Use Code to comply with recently enacted state legislation restricting the installation of nonfunctional turf, artificial turf, and invasive plant species in new development and redevelopment projects. The amendment ensures consistency with House Bill 25-1113 and positions the Town to proactively reduce water demand, improve long-term sustainability, and advance environmentally responsible landscaping practices in land use and development.
